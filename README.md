# 🔥 Chipuha — голосовой мессенджер с видео-комнатой

**Chipuha** — это веб-приложение для общения в реальном времени: текстовый чат, голосовые сообщения, файлообмен, голосовой канал (WebRTC) и синхронизированная видео-комната (YouTube). Проект написан на Python (Flask) с использованием Socket.IO для двусторонней связи.

## 🚀 Основные возможности

- 📝 **Текстовый чат** с историей, ответами на сообщения, удалением (для всех или только для себя).
- 🎤 **Голосовые сообщения** — запись и отправка аудио (WebM/MP4) с удобным плеером.
- 📎 **Файлообмен** — отправка любых файлов, изображений (с предпросмотром).
- 🔊 **Голосовой канал** — общение в реальном времени через WebRTC (Peer-to-Peer) с регулировкой громкости для каждого участника.
- 🎬 **Видео-комната** — синхронный просмотр YouTube-видео с очередью, чатом и списком зрителей.
- 🔔 **Уведомления** о новых сообщениях (звуковые и счётчик в заголовке вкладки).
- 👥 **Список онлайн-пользователей** и история смены ников.
- 🔒 **Аутентификация** — регистрация и вход с хешированием паролей.

## 🛠️ Технологии

**Backend**  
- Python 3.8+  
- Flask  
- Flask-SocketIO  
- Simple-Peer (WebRTC)  
- Cryptography 

**Frontend**  
- Vanilla JS (ES Modules)  
- Socket.IO Client  
- Simple-Peer (клиентская часть)  
- Web Audio API (уведомления, анализ громкости)
